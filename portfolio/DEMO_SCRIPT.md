# Demo Script

1. Run `make test` and explain the C fixture tests and API tests.
2. Start the API with `make run`.
3. Open `/docs` and inspect health/readiness endpoints.
4. Call `POST /api/v1/collect` on Linux/WSL and inspect the versioned metrics payload.
5. Create a memory alert rule and inspect `/api/v1/alert-rules`.
6. Review architecture and threat model; clearly explain that authentication and background scheduling are not implemented yet.
